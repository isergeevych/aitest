Тема: AI-агент для анализа доходов и расходов

Описание: 
- анализирует траты,
- прогнозирует расходы,
- советует оптимизацию,
- строит аналитику.

В качестве источников базы знаний используются:
-статьи по финансовой грамотности;
-рекомендации по управлению бюджетом;
-FAQ по категориям расходов;
-советы по экономии;
-инструкции по финансовому планированию;
-аналитические материалы;
-документы и справочные материалы.

После поиска информации AI-агент формирует персонализированный ответ с учетом:
-доходов пользователя;
-структуры расходов;
-финансовых привычек;
-текущих финансовых показателей;
-найденных материалов из базы знаний.

### Экономика AI-решения

Для расчёта использован сценарий 1 000 пользователей, каждый из которых выполняет в среднем 5 запросов в день. Таким образом, система обрабатывает около 5 000 запросов в день или 150 000 запросов в месяц. Средний объём одного запроса с учётом контекста базы знаний принят равным 1 500 входным токенам, средний объём ответа — 800 выходным токенам. Это соответствует 225 млн входных и 120 млн выходных токенов в месяц.

При использовании GPT-5.4 ориентировочная стоимость LLM-инференса составляет $2 362,50 в месяц, Gemini 3.1 Pro — $1 890 в месяц, GPT-5 mini — $296,25 в месяц. Расчёт учитывает только стоимость входных и выходных токенов и не включает дополнительные расходы на RAG, хранение данных, базы данных, мониторинг и другие инфраструктурные компоненты.

Для локального развёртывания в качестве учебного варианта рассматривается сервер с GPU уровня NVIDIA RTX 5090 и 32 ГБ видеопамяти. При условной стоимости конфигурации 300 000 рублей, сроке использования 36 месяцев и дополнительных расходах на электроэнергию около 5 000 рублей в месяц расчётная стоимость владения составляет около 13 300 рублей в месяц.

Для дипломного проекта целесообразно рассматривать гибридную архитектуру: простые и массовые запросы обрабатывать локальной моделью, а сложные финансовые запросы направлять в облачную модель. Такой подход позволяет контролировать стоимость при росте количества пользователей и одновременно сохранять возможность использовать более мощные модели для сложного анализа. Окончательный выбор модели должен учитывать не только стоимость, но также качество ответов, скорость, требования к конфиденциальности финансовых данных и фактическую производительность локальной модели.

### Точка безубыточности

При принятых допущениях локальная инфраструктура обходится примерно в 13 333 рубля в месяц. Для GPT-5.4 расчётная стоимость одного запроса составляет около $0,01575 при среднем объёме 1 500 входных и 800 выходных токенов. При условном курсе 80 рублей за доллар точка безубыточности составляет около 10 600 запросов в месяц, что соответствует примерно 71 пользователю при среднем использовании 5 запросов в день.

Таким образом, при небольшом количестве пользователей использование облачной модели не требует первоначальных затрат на собственное оборудование. При увеличении нагрузки прямые расходы на API растут пропорционально количеству запросов, тогда как локальная инфраструктура имеет преимущественно фиксированную стоимость. Однако окончательное решение нельзя принимать только по стоимости: необходимо учитывать качество локальной модели, производительность, стоимость обслуживания, резервирование, энергопотребление, безопасность финансовых данных и возможность масштабирования.
